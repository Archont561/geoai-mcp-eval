## Description

Pilot phase: 3 task families × two interfaces × r=2. Pilot runs estimate effects and validate the instrument; they are not confirmatory.

Exit criteria:

- Three pilot tasks conform to schema v1.
- The task-suite validator passes.
- Oracle determinism produces three identical verdicts per fixed artefact.
- Human reference H is executed and oracle-verified.
