# Deliberately not specified

**Status:** pre-implementation design specification (post-professor-consultation).

---

The following are **intentionally absent** from this specification to keep it
falsifiable and frozen. All are derived post-pilot from this spec’s data:

- **Implementation** (server/middleware/catalogue code, results pipeline),
- **RESULTS**, **DISCUSSION**, **SUMMARY/PODSUMOWANIE**,
- thesis typography, defence slides.

Any claim phrased as “MCP is better/worse than code” is out of scope. The spec
can only license “these interfaces differ in executed-artefact correctness on
this frozen setup, by this much, within these limits” — or fail to.
